# Glossário (T13)

| Termo | Definição |
|---|---|
| **Agenda única** | Calendário central onde ficam todas as reservas de todos os espaços. |
| **Administrador** | Pessoa responsável por gerenciar espaços, bloqueios, cotas e relatórios. |
| **Auditoria** | Registro de quem fez cada reserva, cancelamento ou bloqueio. |
| **Bloqueio** | Período em que um espaço não pode ser reservado (manutenção, evento). |
| **Conflito de horário** | Situação em que duas reservas querem o mesmo espaço no mesmo horário. |
| **Cota** | Limite de horas que um usuário pode reservar em um período. |
| **Equidade** | Distribuição justa dos espaços entre todos os cursos e faculdades. |
| **Espaço** | Local compartilhado da universidade: sala de estudo, laboratório, auditório ou área esportiva. |
| **Grupo de pesquisa** | Conjunto de pessoas que fazem pesquisa juntas e podem reservar espaços. |
| **Prioridade rotativa** | Regra em que a prioridade de reserva muda entre cursos e faculdades. |
| **Reserva** | Pedido confirmado para usar um espaço em uma data e horário. |
| **Usuário** | Pessoa da comunidade universitária que usa o sistema (estudante, docente etc.). |
